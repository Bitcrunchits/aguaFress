1. Introducción y Visión del Proyecto

AguaFress es una plataforma marketplace web que conecta vendedores y consumidores de agua/soda en Argentina, reemplazando el modelo tradicional de visitas semanales fijas por un sistema de pedidos digitales con confirmación de visita.

✅ Pedido directo del consumidor

Ninguna app en Argentina lo permite

✅ Confirmación de visita

Evita viajes improductivos

✅ Pedidos fuera del día de ruta

Flexibilidad total

✅ Ruta inteligente con GPS

Integración Google Maps/Waze

✅ Valoraciones y favoritos

Experiencia e-commerce

✅ Marketplace bidireccional

Une ambas partes activamente

9. Flujos de Usuario

9.1 Flujo de Autenticación

[USUARIO] → /auth/login → [OK] → JWT Token → [APP SEGÚN ROL]

9.2 Flujo de Compra

[CONSUMIDOR] → Ver Catálogo → Agregar al Carrito → Checkout →
→ Elegir Pago (anticipado/contra entrega) → Crear Pedido (PENDIENTE) →
→ Confirmar Visita → [VENDEDOR] → Ruta con GPS → Entregar/Cancelar

9.3 Aislamiento de Cartera

Cada vendedor solo puede ver y gestionar sus propios clientes. Las consultas incluyen siempre: WHERE vendedor_id = 'id-del-vendedor'

11. Criterios de Aceptación

11.1 Funcionales

  • ✓ Usuario puede registrarse y hacer login
  • ✓ Consumidor ve catálogo de su vendedor asignado
  • ✓ Consumidor puede agregar productos al carrito y realizar pedido
  • ✓ Consumidor puede pagar anticipado o contra entrega
  • ✓ Consumidor puede confirmar/cancelar visita
  • ✓ Vendedor ve sus pedidos confirmados
  • ✓ Vendedor puede gestionar productos y generar informes
  • ✓ Vendedor tiene mapa con GPS
  • ✓ Aislamiento de datos funciona correctamente

11.2 No Funcionales

  • ✓ Tiempo de respuesta < 2 segundos
  • ✓ HTTPS configurado
  • ✓ Contraseñas hasheadas con bcrypt
  • ✓ JWT expira correctamente (24h)
  • ✓ Docker compose levanta todo
  • ✓ Tests unitarios pasando
