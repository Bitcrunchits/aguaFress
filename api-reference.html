AguaFress API

Base URL: http://localhost:3000/api/v1  |  Docs UI: http://localhost:3000/api/docs  |  OpenAPI spec: http://localhost:3000/api/openapi.json
Autenticación: Los endpoints protegidos requieren Authorization: Bearer <token>. Los roles se especifican por endpoint. El token JWT se obtiene de auth/login.

IDs: userId NUNCA va en el body. Se extrae del token JWT. IDs en parámetros de ruta van como query params.

Paginación: Endpoints de listas aceptan ?page=1&limit=20 (opcional, defaults: page=1, limit=20).

Fechas: Siempre ISO 8601 strings.
