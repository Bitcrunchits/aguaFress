1. Introducción

El RpcExceptionFilter es un filtro global que captura todas las excepciones lanzadas en usuario-service, tanto en contexto HTTP (REST) como RPC (TCP para microservicios).

📖 Filosofía: El cliente siempre recibe una respuesta JSON consistente con statusCode, message, path y timestamp. Los errores inesperados (500) nunca filtran detalles internos al cliente, pero se loguean con stack trace completo para debuggear.

2.1 HTTP — request/respone

@Catch()
export class RpcExceptionFilter implements ExceptionFilter {
  catch(exception: unknown, host: ArgumentsHost) {
    if (host.getType() === 'rpc') return this.handleRpcError(exception);
    this.handleHttpError(exception, host);
  }
}

2.2 RPC — comunicación entre microservicios (TCP)

Cuando un microservicio llama a otro por TCP y este tira un error, NestJS por defecto lo reemplaza por "Internal server error". Nuestro filter preserva el mensaje original antes de que eso pase.

3. Casos prácticos

3.1 Error controlado del negocio

throw new ConflictException('El email ya está registrado');
Qué recibe el clienteQué se loguea
409 + "El email ya está registrado" WARN HTTP 409 — /api/auth/register: El email ya está registrado

➡️ El mensaje se preserva. Sin stack trace (es un error esperado).

3.2 Error de validación (ValidationPipe)

// Body inválido automáticamente detectado por ValidationPipe
Qué recibe el clienteQué se loguea
400 + ["email inválido", "contraseña muy corta"] WARN HTTP 400 — /api/auth/register: email inválido; contraseña muy corta
✅ Mejora clave: La versión anterior usaba exception.message que devolvía solo "Bad Request" — perdiendo los detalles de validación. Ahora usamos exception.getResponse() que preserva el array completo.

3.3 Error inesperado (bug, DB caída)

// Prisma lanza un error de conexión (no es HttpException)
Qué recibe el clienteQué se loguea
500 + "Internal server error" ERROR HTTP 500 — /api/auth/login: Internal server error

⚠️ Seguridad: El cliente nunca ve el stack trace ni detalles internos. Solo el equipo de desarrollo los ve en los logs.

7. SOLID compliance

PrincipioCómo se aplica
SRP — Single Responsibility Una sola responsabilidad: capturar, loguear y formatear errores
OCP — Open/Closed @Catch() sin filtro atrapa todo. No hay que modificarlo para nuevos tipos de error
LSP — Liskov Substitution Trata HttpException, RpcException y Error según su tipo base
ISP — Interface Segregation Implementa solo ExceptionFilter → un único método catch()
DIP — Dependency Inversion Depende de HttpAdapterHost (abstracción de NestJS), no de Express (concreto)

9. Código fuente

usuario-service/src/common/filters/rpc-exception.filter.ts:

import {
  Catch, ExceptionFilter, HttpException, HttpStatus, Logger,
  type ArgumentsHost,
} from '@nestjs/common';
import { HttpAdapterHost } from '@nestjs/core';
import { RpcException } from '@nestjs/microservices';
import { Observable, throwError } from 'rxjs';

@Catch()
export class RpcExceptionFilter implements ExceptionFilter {
  private readonly logger = new Logger(RpcExceptionFilter.name);
  constructor(private readonly httpAdapterHost: HttpAdapterHost) {}

  catch(exception: unknown, host: ArgumentsHost): Observable<any> | void {
    const type = host.getType();
    if (type === 'rpc') return this.handleRpcError(exception);
    this.handleHttpError(exception, host);
  }

  // ── RPC ───────────────────────────────────────────────────
  private handleRpcError(exception: unknown): Observable<never> {
    if (exception instanceof HttpException) {
      const payload = this.extractErrorPayload(exception);
      this.logger.warn(`RPC — ${this.serializeForLog(payload)}`);
      return throwError(() => new RpcException(payload));
    }
    if (exception instanceof RpcException) {
      this.logger.warn(`RPC — RpcException: ${JSON.stringify(exception.getError())}`);
      return throwError(() => exception);
    }
    this.logger.error(`RPC — Unhandled: ${(exception as Error).message}`, (exception as Error).stack);
    return throwError(() => new RpcException({
      statusCode: HttpStatus.INTERNAL_SERVER_ERROR,
      message: 'Internal server error',
    }));
  }

  // ── HTTP ──────────────────────────────────────────────────
  private handleHttpError(exception: unknown, host: ArgumentsHost): void {
    const { httpAdapter } = this.httpAdapterHost;
    const ctx = host.switchToHttp();
    const path = httpAdapter.getRequestUrl(ctx.getRequest());
    const isHttpException = exception instanceof HttpException;

    const responseBody = isHttpException
      ? { ...this.extractErrorPayload(exception), path, timestamp: new Date().toISOString() }
      : { statusCode: HttpStatus.INTERNAL_SERVER_ERROR, message: 'Internal server error', path, timestamp: new Date().toISOString() };

    const logMsg = this.serializeForLog(responseBody);
    if (responseBody.statusCode >= 500) {
      this.logger.error(`HTTP ${responseBody.statusCode} — ${path}: ${logMsg}`, (exception as Error).stack);
    } else {
      this.logger.warn(`HTTP ${responseBody.statusCode} — ${path}: ${logMsg}`);
    }

    httpAdapter.reply(ctx.getResponse(), responseBody, responseBody.statusCode);
  }

  // ── Helpers ───────────────────────────────────────────────
  private extractErrorPayload(exception: HttpException): Record<string, any> {
    const response = exception.getResponse();
    if (typeof response === 'string') return { message: response, statusCode: exception.getStatus() };
    if (typeof response === 'object' && response !== null) return { statusCode: exception.getStatus(), ...response };
    return { message: exception.message, statusCode: exception.getStatus() };
  }

  private serializeForLog(body: Record<string, any>): string {
    if (Array.isArray(body.message)) return body.message.join('; ');
    if (typeof body.message === 'string') return body.message;
    return JSON.stringify(body);
  }
}
